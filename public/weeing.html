위잉치킨

틱톡·유튜브 라이브 채팅 주문을 자동으로 수집하고, 라벨까지 뽑아주는 라이브 커머스 주문 프로그램.

최신 버전을 확인하고 있어요…
🪟 Windows 10 / 11 전용
🛒 자동 주문 수집
채팅에 번호만 치면 상품·수량·고객 자동 정리
🖨️ 라벨 자동 출력
주문마다 QR·고객번호·상품 라벨 즉시 인쇄
🔗 ERP 실시간 연동
재고·고객·주문이 우리 ERP와 실시간 동기화
⚙️ 설정 제로
라이선스 키만 넣으면 접속·프린터 자동 세팅

설치 방법

1
프로그램 다운로드
위 버튼을 눌러 설치파일을 받고 실행하세요. (Windows 보안 경고가 뜨면 “추가 정보 → 실행”)
2
라이선스 키 입력
처음 실행하면 라이선스 키를 물어봐요. 발급받은 키를 입력하면 인증됩니다.
3
끝 — 자동 연결
ERP 접속정보·프린터 용지까지 자동으로 세팅돼요. 바로 방송에 연결해 주문을 받으세요.
라이선스 키가 없으신가요?
위잉치킨은 라이선스 키가 있어야 실행됩니다. 도입 문의는 담당자에게 연락 주세요. 키 발급 후 이 페이지에서 프로그램을 받아 바로 사용하실 수 있습니다.
